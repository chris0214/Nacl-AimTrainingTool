# 本地发布准备

1. 运行`tools/audit-source.ps1`，审查待提交文件列表与许可清单。
2. 在干净目录从源码导入，运行代表性回归及原生窗口外观/镜片检查。
3. 安装相同版本的Godot导出模板，执行`tools/godot.ps1 -Task export`。
4. 从项目外目录启动`build/NaclAimTrainingTool.exe`，检查Bot三种外观、
   两种武器、开镜、菜单许可、地图编辑器SVG图标及内置示例加载。
5. 保留build中的项目、图标、Godot及其组件许可；只分发这一版的导出文件。
6. 由维护者审查Git差异、许可证、发布说明和包内容后，再决定提交/推送/创建Release。

旧本地原型的EXE与资源不属于此源码版本；不要混入新发布包。
源码目录只包含项目源文件和Lucide图标，不需要从旧原型补拷模型或贴图。

MIT许可已作为本地准备方案写入，正式推送前由维护者确认。
本轮整理不自动提交、不推送，不创建GitHub Release。

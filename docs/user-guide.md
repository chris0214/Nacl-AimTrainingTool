# 操作与设置

Esc面板包含Bot、键鼠、显示、玩家、场景与声音、准星与曳光六页。
各参数旁的问号解释作用和边界。滑块即时生效；精确数字输入按回车或失焦确认。

## 训练

Bot页可以选择胶囊/机器人、体宽、准度、速度和步法。100档瞄准为硬锁，
仍遵守射程与遮挡。进阶模式开放跳跃/空中控制。
共同基础速度影响双方；玩家可选瞬时满速或保留加速度。

键鼠页填写鼠标实际DPI后调cm/360；DPI不会自动检测。
显示页可调分辨率、帧率、VSync、模拟频率。显示更改需要确认，否则还原。
性能不足时可能暂停并标记非计分。

## 单发与瞄准镜

玩家页切换单发项目，先到25/50分结束；双方独立冷却。
选择按住或点击切换开镜、倍率和镜内灵敏度。
镜内灵敏度100%按倍率降低角速度，近似保持中心微小移动速度。

准星与曳光页提供固定预览、五套普通预设、内外线/中心点/描边/透明度。
镜片效果在实际单发开镜时查看：独立放大、边缘畸变、暗角和渲染比例。
中心55%镜片半径不畸变，准星不变形；镜外亮度由外围遮罩控制。
设为0可关闭畸变或暗角。关闭仅镜内放大可恢复全屏放大。

结算或「结束并复盘」提供逐枪偏差、按键方向和实际速度快照，
可筛选打空。角度偏差相对目标中心，不等于距离命中盒边缘的距离。

## 白盒地图

场景与声音页进入地图编辑器。支持Box、楼梯、斜坡、阻挡体积；
先画底面、再确定高度，也可通过面手柄推拉六面。
拖动可吸附，右键/Esc取消。楼梯外观保留台阶，行走碰撞用连续坡面减少抖动。

- 中键环绕，Shift+中键平移，滚轮缩放。
- 右键按住转向，WASD移动，Q/E升降，Shift加速。
- F聚焦，Ctrl+D复制，Delete删除，Ctrl+Z撤销，Ctrl+Y重做，Ctrl+S保存。
- 放置玩家/Bot出生点，保存或直接试玩；回到编辑器保留未保存修改。
- 地图选择页可导入 `.lgmap`。内置示例修改后另存。

无限平面没有水平碰撞边缘，但不意味着无限导航或无限浮点精度。
地图最多256个物体，必须有有效出生点与连通的可行走路径。
暂不提供复杂跳跃规划或逐台阶脚部IK。
